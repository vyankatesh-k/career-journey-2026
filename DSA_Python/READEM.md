# 📘 DSA in Python – April 2026 Journey

This folder contains my structured Data Structures & Algorithms (DSA) preparation using Python.

The goal is to build strong problem-solving skills by following a disciplined approach:
- Start with brute force
- Optimize using patterns
- Analyze time and space complexity
- Write clean and reusable code

---

## 🚀 Learning Roadmap

### 📅 Day 1 – Arrays & Strings Basics
Focus:
- Array traversal
- String traversal
- Time complexity (O(1), O(n), O(n²))
- Optimization mindset

Files:
- `max_element.py` → Find maximum element (brute vs optimized + benchmarking)
- `count_vowels.py` → Count vowels using multiple approaches
- `reverse_str.py` → Reverse string (brute, list, two-pointer, pythonic)

---

### 📅 Day 2 – Two Pointer Technique
Focus:
- Opposite direction pointers
- Reducing nested loops → O(n)

Files:
- `palindrome.py` → Check palindrome using two pointers
- `pair_sum.py` → Find pair with given sum in sorted array

---

### 📅 Day 3 – Sliding Window
Focus:
- Fixed size window
- Variable size window
- Optimizing subarray/substring problems

Files:
- `sliding_window.py` →
  - Max sum subarray (fixed window)
  - Longest substring without repeating characters (variable window)

---

### 📅 Day 4 – Prefix Sum
Focus:
- Precomputation technique
- Range queries optimization
- Subarray sum problems

Files:
- `prefix_sum.py` →
  - Range sum queries using prefix array
  - Count subarrays with given sum (using hashmap)
